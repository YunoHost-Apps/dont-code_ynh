Dont-code is a low-code / no-code platform letting users create their own applications based on complete feature sets developed by IT.
You can find more information here: https://dont-code.net

This YunoHost app installs the full Dont-code suite: dashboard, application host, bundled plugins, project/data services, and MongoDB databases.

### Features

- Dashboard to manage Dont-code projects and access AI-assisted application generation.
- Application host and plugins to preview and run AI-created applications.
- Project and data REST services backed by MongoDB.
- Document upload/storage support.
- Projects and user data are included in the YunoHost backup process.
